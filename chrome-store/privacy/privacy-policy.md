# llmon cha Privacy Policy

Last updated: 2026-05-10

llmon cha is a browser AI chat extension that lets users connect custom LLM APIs and local Ollama models.

## Data We Store Locally

llmon cha stores the following data in the browser’s local extension storage:

- Model configuration, such as provider, base URL, model name, temperature, max token settings, and selected prompt preset.
- API keys entered by the user.
- Conversation history.
- Prompt presets created by the user.
- Interface preferences, such as language, color scheme, theme, and sidebar state.

This data is stored locally in the user’s browser through Chrome extension storage.

## Data Sent to Model Providers

When the user sends a message, llmon cha sends the conversation content and relevant model settings to the configured model endpoint. This may be:

- A third-party OpenAI-compatible API provider selected by the user.
- A local Ollama service running on the user’s computer.

llmon cha does not operate its own cloud model service and does not collect or receive the content of user conversations.

## API Keys

API keys are stored locally in the browser extension storage. They are used only to authenticate requests to the model endpoint configured by the user.

Users should only enter API keys for services they trust.

## Remote Code

llmon cha does not load or execute remote code as part of its extension UI. Model responses are treated as content and rendered inside the chat interface.

## Data Sharing

llmon cha does not sell, share, or transfer user data to the developer’s own servers.

User messages may be transmitted to third-party model providers only when the user configures and uses those providers. Those providers process data according to their own terms and privacy policies.

## User Control

Users can:

- Delete individual conversations.
- Clear conversation history.
- Delete custom prompt presets.
- Reset model settings.
- Restore factory settings, which clears local settings, API keys, prompt presets, and conversation history.

## Contact

For privacy questions, use the support contact provided in the Chrome Web Store listing.
