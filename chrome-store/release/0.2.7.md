# lemon cha 0.2.7

## Changes

- Add sidebar shortcuts for built-in and custom prompt presets, including icon-only shortcuts when the sidebar is collapsed.
- Preserve entered text when selecting, switching, or removing a preset. Show a compact preset tag inside the composer with instruction preview and an adjacent cancel button.
- Keep the composer height stable during preset changes and align tag colors, chevrons, shape, hover, focus, and press feedback with the existing design system.
- Refine the names, task hints, and instructions for five built-in presets across all eight interface languages.
- Store the resolved preset snapshot with each sent message so regeneration and subsequent context retain the original instructions.
- Update model selectors to use each service’s configured model name without extra custom/current-model entries. Retain independently saved custom configurations and isolate their endpoint and API key from other services.
- Support older saved endpoint and model field names.

## Validation

- `pnpm lint`, `pnpm typecheck`, and all 28 Node tests pass.
- `pnpm build:chrome` succeeds.
- Isolated Chrome checks cover preset interactions, keyboard/hover/press feedback, eight languages, desktop and 320/400px layouts, stable composer geometry, model-list deduplication, and configuration switching using fixture credentials.
- Live provider requests and a local Ollama server were not exercised for this release.

## Package

- Chrome: `lemon-cha-extension-0.2.7.zip`.
- No permission changes.
- This release publishes the Chrome package only.
