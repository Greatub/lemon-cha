# lemon cha Chrome Web Store 文案（简体中文）

## 名称

lemon cha

## 简短说明

轻量自然的浏览器 AI 对话插件，支持自定义 LLM API、Ollama 本地模型、提示词预设与多语言工作流。

## 详细说明

lemon cha 是一个独立标签页式的浏览器 AI 对话插件，适合在阅读、写作、翻译、代码审查和日常整理中快速开启对话。

你可以：

- 连接自己的 OpenAI-compatible API。
- 使用本地 Ollama 模型。
- 为不同模型分别保存 API、模型名、温度、最大输出长度和系统提示词。
- 使用提示词预设快速进入总结、翻译、写作、排错等工作流。
- 管理多段对话，支持文件夹整理、重命名和 Markdown 导出。
- 切换界面语言、回答语言和默认翻译目标语言。

lemon cha 不提供自有云模型服务。你的请求会发送到你自己选择的第三方模型接口，或发送到本机 Ollama 服务。

## 特色

- 独立标签页聊天界面
- 支持流式输出
- 支持本地 Ollama
- 支持自定义 API
- 支持多语言界面
- 支持 Prompt 预设
- 支持历史会话管理
- 支持导出 Markdown

## 隐私摘要

- API Key 保存在浏览器本地扩展存储中。
- 对话、设置和提示词预设保存在浏览器本地。
- 扩展不会把数据上传到 lemon cha 自有服务器。
- 用户消息仅会发送到其自行配置的模型服务端点。
