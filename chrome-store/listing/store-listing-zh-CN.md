# lemon cha Chrome Web Store 文案（简体中文）

## 名称

lemon cha

## 简短描述

清新轻量的浏览器 AI 对话插件，支持自定义 LLM API 和本地 Ollama 模型。

## 详细描述

lemon cha 是一个面向浏览器工作的 AI 对话插件。它提供独立标签页式的聊天界面，让你可以连接自己的 LLM API，也可以使用本地 Ollama 模型进行对话。

它适合日常写作、翻译润色、网页内容总结、代码审查、问题排查和任务规划等工作流。界面风格清新、自然、低压，尽量减少传统 AI 工具的技术压迫感。

主要功能：

- 支持 OpenAI-compatible API，包括 DeepSeek、OpenAI、通义千问、Kimi、SiliconFlow、OpenRouter、Groq 等服务。
- 支持本地 Ollama 模型，可通过 `http://127.0.0.1:11434` 连接本机模型服务。
- 支持流式输出，让模型回复过程更自然。
- 支持多会话管理、会话重命名、删除、文件夹分组和 Markdown 导出。
- 支持 Prompt 预设模板，包括总结提炼、翻译润色、代码审查、问题排查、写作改稿和任务规划。
- 支持多语言界面：简体中文、繁體中文、English、日本語、한국어、Français、Español、Deutsch。
- 支持日间、夜间和跟随系统的主题模式。
- API Key 保存在浏览器本地存储中，不会上传到 lemon cha 自有服务器。

隐私说明：

lemon cha 本身不提供云端模型服务，也不会收集你的对话内容。你的消息会根据你选择的模型配置发送到对应的第三方 API 服务或本地 Ollama 服务。请根据所使用模型服务的隐私政策判断是否适合发送敏感内容。
