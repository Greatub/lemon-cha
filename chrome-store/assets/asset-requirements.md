# Chrome Web Store Asset Requirements

## Already available in the extension ZIP

- Extension icon: `assets/icon-128.png`
- Additional extension icons: `16px`, `32px`, `48px`

## Required for store listing upload

- At least one screenshot of the product UI.
- One small promotional image.

Recommended screenshot topics:

1. Main chat page with model selector and composer.
2. Settings page with provider configuration.
3. Prompt preset workflow.
4. Local Ollama model selection or successful connection state.

## Recommended image specs

- Small promotional image: `440 x 280`
- Optional marquee promotional image: `1400 x 560`
- Screenshots should avoid API keys, tokens, real private conversations, and unrelated desktop content.

## Suggested asset filenames

- `screenshots/chat-main-1280x800.png`
- `screenshots/settings-models-1280x800.png`
- `screenshots/prompt-presets-1280x800.png`
- `promo-small-440x280.png`
- `promo-marquee-1400x560.png`
