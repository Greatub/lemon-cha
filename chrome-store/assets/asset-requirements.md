# 商店图形素材要求

## 必需

### Store icon

- 尺寸：128×128 px
- 当前文件：`assets/icon-128.png`
- 状态：已有

### Screenshot

- 数量：至少 1 张，建议 3 到 5 张
- 尺寸：1280×800 或 640×400 px
- 格式：PNG 或 JPEG
- 要求：方角、无留白、展示真实使用体验
- 状态：需要从实际插件界面截取

建议文件名：

- `screenshot-01-main-chat-1280x800.png`
- `screenshot-02-model-settings-1280x800.png`
- `screenshot-03-prompt-presets-1280x800.png`
- `screenshot-04-ollama-local-1280x800.png`
- `screenshot-05-dark-mode-1280x800.png`

### Small promotional tile

- 尺寸：440×280 px
- 格式：PNG 或 JPEG
- 状态：需要制作或导出
- 建议：尽量少文字，突出 lemon/chat 品牌图形和轻量 AI 对话定位。

## 可选

### Marquee promotional tile

- 尺寸：1400×560 px
- 格式：PNG 或 JPEG
- 状态：可选

## 注意

- 截图不要包含真实 API Key、私人对话或真实用户数据。
- 多语言版本可以提供本地化截图，但首版可以先使用主语言截图。
- 宣传图不建议放大量文字，避免在小尺寸下不可读。
